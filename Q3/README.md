# Q3 - Sales Report

## Files

- ReportManual.java
- ReportTwr.java

## Setup

Create `store1.txt`, `store2.txt` and `store3.txt` in this folder. Each file has one number on every line. Do not create `missing.txt`, it is used to test the failure.

## How to compile and run

```
javac ReportManual.java
java ReportManual

javac ReportTwr.java
java ReportTwr
```

## Result

Both programs write a summary file and print a failed message for every bad or missing file. Both give the same total. ReportManual writes summary_manual.txt and ReportTwr writes summary_twr.txt.
